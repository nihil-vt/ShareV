The ShareX experience, finally on Linux

ShareV is the open-source screen capture, annotation, and sharing tool built natively for Linux. Capture, annotate, record, upload, and share — all in one app.

Download for Linux View on GitHub
Features

Everything ShareX does. On Linux.

A complete screen capture and sharing workflow, built for Wayland and X11.

Screen Capture

Region, fullscreen, and window capture with delay timer and monitor picker. Works on Wayland and X11.

Screen Recording

Record to MP4, WebM, or animated GIF with system audio, microphone, or both. Configurable frame rate.

Annotation Editor

Draw rectangles, ellipses, arrows, pen strokes, add text, pixelate sensitive info, and crop — with undo/redo.

Task Chains

Automate your post-capture and post-upload workflows: save, copy, upload, pin, run commands, notify.

Upload & Share

Upload to Imgur, any HTTP endpoint, or a custom shell command. Links copied as URL, Markdown, or HTML.

Pin to Screen

Keep any capture floating on your desktop in a borderless, always-on-top, transparent window.

Global Hotkeys

XDG Portal integration on Wayland, tauri-plugin-global-shortcut on X11. Or bind the CLI in your compositor.

Headless CLI

Scriptable commands for capture, record, upload, and pin. Designed for compositor keybindings.

Auto-Updates

Signed in-app updates from GitHub Releases. .deb, .rpm, and AppImage packages for major distributions.

Showcase

See it in action

Powerful features, beautifully integrated.

Annotation Editor

Mark up screenshots with a full set of tools. No external editor needed.

  • Rectangles, ellipses, arrows, and freehand pen
  • Text tool with customizable colors and stroke width
  • Pixelate sensitive information before sharing
  • Undo/redo with up to 20 steps

Task Chains

Automate what happens after each capture and upload. Define your own pipeline.

  • Post-capture: save, copy, edit, upload, pin, notify
  • Post-upload: copy link, notify, open in browser
  • Ordered, editable task lists
  • Run custom shell commands with file substitution

Pin to Screen

Keep reference images, notes, or designs always visible on your desktop.

  • Borderless, transparent overlay window
  • Always on top, draggable, double-click to close
  • Available as a task, tray action, or CLI command

Yes! ShareV supports both Wayland and X11. On wlroots-based compositors like Hyprland and Sway, it uses grim and slurp for capture. On X11, it uses ImageMagick's import. Global hotkeys use XDG Portal on Wayland and tauri-plugin-global-shortcut on X11.
You need an Imgur API Client-ID (free). Register an application on Imgur, then paste the Client-ID in ShareV under Settings → Uploads. Uploads are anonymous — no Imgur account required.
Absolutely. ShareV includes a headless CLI: sharev capture region, sharev record fullscreen, sharev upload shot.png, and more. Flags like --delay, --monitor, and --window are available. Perfect for binding in Hyprland, Sway, or any compositor.
Yes. ShareV checks GitHub Releases for signed updates and installs them in-app. Flatpak installations delegate to the Flatpak updater. Updates are verified with cryptographic signatures for security.
